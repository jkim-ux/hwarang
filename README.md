# hwarang — 숙제 리뷰 데스크

학생들이 구글 드라이브 폴더에 올린 구글 문서 숙제를 Claude가 읽고 리뷰한 결과를 한 화면에서 보는 교사용 도구입니다.

- 게시된 페이지: https://claude.ai/code/artifact/b3743ca6-bd7f-4fd2-8b24-fcf536678b5b
- 자동 확인: 매일 08:00 · 17:00 (KST). claude.ai/code 의 Routines 에서 관리 (루틴은 드라이브 커넥터가 연결된 원래 세션으로 돌아와 실행됨. 자세한 내용은 `review-desk/routine-prompt.md`)
- 수동 확인: 페이지의 **지금 확인하기** 버튼

## 구성

| 파일 | 역할 |
| --- | --- |
| `review-desk/index.html` | 페이지 소스. Artifact 로 게시하며 `db`, `sample`, `mcp`(Google Drive) 런타임 기능을 씀 |
| `review-desk/routine-prompt.md` | 자동 실행 루틴에 들어가는 프롬프트 (새 세션이 매번 이 지시로 실행) |

## 동작 방식

1. **설정** (`config/main`): 과목 폴더 목록(폴더 하나 = 과목 탭 하나, 짧은 탭 이름 포함), 건너뛸 하위 폴더, 최근 며칠, 최소 글자 수, 리뷰 기준(rubric). 페이지의 설정 패널에서 편집.
2. **과목 탭**: [전체] 탭과 폴더별 탭. 탭마다 확인 안 한 리뷰 수가 표시되고, 과목 탭에서 "지금 확인하기"를 누르면 그 과목 폴더만 확인.
3. **문서 수집**: 감시 폴더 바로 아래의 구글 문서 + 한 단계 아래 하위 폴더(학생 폴더)의 구글 문서. 하위 폴더 이름에서 수업 이름을 뺀 부분이 학생 이름.
4. **리뷰 대상**: 최근 N일 안에 수정됐고, 리뷰가 없거나 리뷰 이후 다시 수정된 문서만.
5. **리뷰 저장** (`reviews/<fileId>`): 점수(0~10), 한 줄 요약, 잘한 점 / 고칠 점 / 다음 단계, 주의 표시, 학생에게 전달할 코멘트.
6. **실행 기록** (`runs/<id>`): 시각, 출처(자동/수동), 검사·리뷰·건너뜀 건수, 오류.

수동 확인은 페이지 안에서 드라이브 조회 → Claude 리뷰 → DB 저장까지 모두 처리하고, 자동 확인은 루틴이 띄운 Claude 세션이 같은 스키마로 DB에 씁니다.

## 제한

- 구글 문서만 리뷰합니다. PDF·워드 파일은 건너뜁니다.
- 문서 안의 그림(도표)은 읽지 못하므로 도표 자체의 정확성은 본문 서술로만 판단합니다.
- 페이지는 claude.ai 안에서 열어야 드라이브 연결과 리뷰 실행이 됩니다.
